You are helping me complete Machinedog.dev.

Machinedog.dev is a general-purpose browser-based AI coding SaaS platform for all clients, not just healthcare. Healthcare/HIPAA is a premium protected tier, not the default product.

The platform should allow anyone to:

1. Sign up.
2. Authenticate through Clerk.
3. Create or join an organization/client account.
4. Choose a subscription plan.
5. Buy or receive usage tokens.
6. Create a project.
7. Import a GitHub repository.
8. Open a secure browser-based coding workspace.
9. Use an AI coding console.
10. Edit files.
11. Save changes.
12. Commit changes back to GitHub.
13. Preview the app.
14. Publish the app.
15. Manage secrets securely.
16. View usage, billing, project history, and audit logs.

The current project was started inside Replit and already has a Machinedog.dev-style interface with a dark premium SaaS look, sidebar navigation, console, preview area, publish/history areas, tokens, clients, projects, orders, and admin-style sections. Preserve the existing visual direction and improve it into a serious SaaS MVP.
